Comic30 Privacy Policy

Comic30 is currently a private MVP testing environment for building game creation workflows. This page is a production placeholder and should be reviewed by counsel before public launch.

Data We Collect

Account details, project prompts, generated game data, build metadata, wallet ledger test events, and audit logs may be stored to operate the creator portal.

How Data Is Used

Data is used to authenticate creators, save projects, generate game content, test build exports, prevent abuse, and prepare app-store readiness material.

Account Deletion

Creators can request account deletion through the portal. The backend includes an account deletion endpoint that removes the account and de-identifies owned projects.

Contact

Email contact@comic30.com for privacy or account requests.
